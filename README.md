# 📈 Stock Market Analysis Dashboard

## 📌 Project Overview

This Power BI dashboard provides a comprehensive analysis of stock market transactions, focusing on revenue, profit, customer activity, ratings, discounts, and transaction status. The dashboard helps stakeholders monitor financial performance, identify trends, and gain actionable insights through interactive visualizations.

## 🎯 Objective

The objective of this dashboard is to analyze stock market transaction data and transform it into meaningful insights for tracking profitability, customer engagement, transaction performance, and business growth.

## 🛠️ Tools Used

• Power BI  
• Power Query  
• DAX (Data Analysis Expressions)  
• Data Modeling  
• Data Cleaning & Transformation  
• Interactive Visualizations  
• KPI Cards  
• Slicers & Filters

## 📊 Dashboard Features

### Revenue & Profit Trend
• Tracks yearly revenue and profit performance.  
• Compares revenue growth against profit growth over time.  
• Identifies peak and low-performing years.

### Discount vs Profit Analysis
• Analyzes the relationship between discounts and profit.  
• Helps evaluate the effectiveness of discount strategies.  
• Identifies optimal discount levels for profitability.

### Rating by Category
• Displays average customer ratings across categories.  
• Compares ratings based on transaction status.  
• Helps identify high-performing categories.

### Revenue by Status
• Shows revenue distribution across transaction statuses.  
• Categories include Completed, Pending, and Cancelled transactions.  
• Helps assess revenue contribution from each status.

### Transaction Count by Status
• Visualizes transaction volume by status.  
• Tracks operational performance and transaction completion rates.  
• Identifies potential bottlenecks in the transaction process.

## 🔍 Key Insights

• Revenue peaked in 2025, reaching approximately 2.3M.  
• Total profit reached 2.89M, indicating strong profitability.  
• Completed transactions generated the highest revenue contribution.  
• Transaction counts are relatively balanced across statuses.  
• Customer ratings remain consistent across categories, averaging around 3.0.  
• Discount levels show a measurable impact on profit generation.  
• The dashboard highlights trends useful for improving profitability and operational efficiency.
